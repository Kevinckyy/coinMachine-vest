# 同批同品种统一方向

自动策略在选出整批账号后，为该品种确定一次方向，再依次安排开仓。随机方向每批仅抽取一次，保存在策略的 `batch_directions` 中；账号间下单间隔、首单提前结束、页面重连及服务重启都不会重新抽取该批方向。当前实际执行仅支持 NQ-PERP；回测每次选定一个品种，也使用相同的批次规则。

考核号与 Live 的方向设置按实际选中的批次合并：全为随机则抽取一次；固定方向与随机混合时，全批采用该固定方向；同批同时出现固定做多和固定做空时，在任何新开仓排队前暂停整批并提示修改配置。不同批次可以使用不同方向。Live 的仓位、止盈止损和回撤规则仍独立应用。

服务端在策略开仓入队及浏览器领取任务前校验同批方向，任务标注 `strategy_run_id` 和 `strategy_batch_number`。已送达任务和实际持仓的方向也作为核对依据；反向任务或其他轮次、批次的旧任务在派发前拦截，不发送浏览器。旧运行缺少方向记录时，根据当前批次已有持仓及已执行记录恢复；有冲突则停止后续开仓，不改写或反向平掉已有持仓。

自动策略页顶部显示固定规则提示，当前执行状态显示该批品种与统一做多/做空方向。随机下单策略版本升为 3，回测模拟版本升为 10，回测逐笔记录增加 `batch_number`；旧历史保持原结果，不自动重算。相同旧种子重跑时，新规则会改变随机数的消耗顺序及结果。

界面还会检查服务返回的 `capabilities.strategy_batch_same_side`。旧服务缺少该能力时明确提示重启，并禁止启动新策略，避免只更新了页面、实际后台仍逐号抽取方向。
